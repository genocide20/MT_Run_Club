# MT Running Club

เว็บบันทึกระยะเดิน–วิ่งและแสดงระยะสะสมจาก Google Sheets

1. ใน Google Sheet ใช้แท็บ `Employee` คอลัมน์ A ชื่อ-นามสกุล และ B สังกัด โดยแถวแรกเป็นหัวตาราง
2. สร้างแท็บ `MT_70` ใส่ A1 `วันเวลาบันทึก`, B1 `ชื่อ-นามสกุล`, C1 `ระยะทาง (km)` หรือให้สคริปต์สร้างเมื่อบันทึกครั้งแรก หากมีข้อมูลอยู่แล้วให้ตรวจสอบลำดับคอลัมน์
3. เลือกส่วนขยาย → Apps Script แล้วแทนที่โค้ดด้วย `Code.gs` ทั้งหมด จากนั้นบันทึก
4. เลือกทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข เลือกเวอร์ชันใหม่ แล้วกดทำให้ใช้งานได้ เพื่อให้ URL เดิมใช้โค้ดใหม่
5. ทดสอบค้นหาและบันทึก แล้วตรวจสอบแท็บ MT_70 หากสร้าง URL ใหม่ ให้อัปเดต `config.js` ด้วย

การเข้าถึงแบบทุกคนทำให้ผู้ที่มี URL ค้นหารายชื่อและบันทึกแทนบุคคลอื่นได้ ระบบนี้ยังไม่มีการยืนยันตัวตนหรือป้องกันสแปม
